# ✈️ TripSplit — Group Trip Settle-Up

TripSplit is a simple, responsive web application that helps friends manage shared trip expenses, calculate individual balances, and settle payments easily.

## 🌟 Features

- **Trip Management:** Set and edit your trip name.
- **Add Members:** Add and remove people from your group.
- **Expense Tracking:** Record expenses and select who paid.
- **Flexible Splitting:** Divide expenses equally or use custom shares.
- **Balance Calculation:** Calculate who owes money and who should receive it.
- **Settlement Suggestions:** Generate suggested payments to settle expenses.
- **Trip Summary:** View total spending, average cost per person, largest expense, and suggested payment count.
- **PDF Bill:** Generate a printable bill and save it as a PDF.
- **CSV Export:** Download expense and settlement details as a CSV file.
- **Light and Dark Mode:** Switch themes according to your preference.
- **Local Storage:** Save trip data in your browser.
- **Responsive Design:** Use the application on desktop and mobile devices.

## 💻 How to Run Locally

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in your web browser.
4. Add group members and start recording expenses.

No additional installation is required.

## 📖 How to Use

1. Enter your trip name.
2. Add all group members.
3. Enter an expense and its amount.
4. Select the person who paid.
5. Choose an equal or custom split.
6. Add the expense to calculate balances.
7. Review suggested payments.
8. Export your bill as PDF or CSV.

## 💾 Data Storage

TripSplit stores trip information in the browser's Local Storage. Data is saved on the current browser and device; it is not automatically synchronized across devices.

Clearing browser data or using a different browser may make the saved trip unavailable. Export your bill to keep a separate copy.

## 🎯 Project Objective

The objective of TripSplit is to simplify group expense management by reducing manual calculations and making shared trip costs easier to track.
