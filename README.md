# TripSplit — Group Trip Settle-Up

A responsive, browser-based shared-expense tracker for group trips.

## Features
- Add/remove travel buddies
- Record an expense and select who paid
- Choose who shares each expense (equal split)
- Automatically calculate net balances
- Suggest simple payments to settle the group
- INR, USD, EUR and GBP display currencies
- Local browser storage; no account or server required
- Responsive layout for mobile and desktop

## Run it
1. Extract the ZIP file.
2. Open `index.html` in a modern browser.
3. Add members, then add expenses.

## Files
- `index.html` — page structure
- `style.css` — responsive styling
- `app.js` — app logic and localStorage persistence

## Notes
This is a front-end project. Data is stored in the browser on the current device and is not synced between users/devices. Expenses are split equally among the selected participants.
